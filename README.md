## 🩸 RedLife

O RedLife é um projeto web desenvolvido com o objetivo de auxiliar postos de saúde no controle de doações de sangue, conectando pacientes que necessitam de transfusão com doadores compatíveis de forma simples e organizada.

Este projeto foi criado com foco educacional e de portfólio, priorizando clareza, boa organização do código e lógica de negócio realista.

### 🎯 Objetivo do Projeto

* Facilitar o gerenciamento de pacientes que necessitam de doação de sangue
* Organizar e visualizar doadores cadastrados
* Identificar compatibilidade entre pacientes e doadores
* Apoiar a tomada de decisão do administrador do sistema

### ⚙️ Funcionalidades
* Dashboard administrativo
* Visualização do estoque de tipos sanguíneos
* Cadastro de pacientes
* Cadastro de doadores
* Listagem completa de pacientes
* Identificação de pacientes sem match
* Sistema de match entre pacientes e doadores
* Visualização de matches confirmados

### 🛠 Tecnologias Utilizadas
* HTML5
* CSS3 (Flexbox e responsividade)
* JavaScript (interações e lógica básica)
* Python (planejado para back-end futuro)

# 🚧 Em desenvolvimento
Atualmente o projeto possui foco no front-end estrutural e prototipação. A integração com back-end e banco de dados está planejada para etapas futuras.

**Projeto desenvolvido para fins educacionais e de aprendizado contínuo.**
